Respuestas de Reflexión

1. ¿Cuál es la diferencia entre un método normal y uno static?

El método normal pertenece a un objeto y requiere crear una instancia de la clase para ser utilizado. Mientras que un método static pertenece a la clase y puede invocarse directamente sin necesidad de crear un objeto.

2. ¿En qué casos usarías sobrecarga de métodos?

La sobrecarga de métodos se utiliza cuando una misma operación se deberia ejecutar con diferentes tipos o cantidades de parámetros, reutilizando el mismo nombre del método y facilitando la comprension del código.
